Rules I work by

Root cause over patches

Three fixes that do not hold mean the model is wrong, not the code.

Deterministic where it counts

The model reads and classifies. Code assembles and reproduces.

The human gate is a feature

A system that says “I am not sure” beats one that is rarely wrong and always confident.

Design is part of the system

If the screen hides what the system knows, the architecture failed.

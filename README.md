# AI Systems Engineering — portfolio page

**Живая версия:** https://wizzhomie.github.io/portfolio/ (GitHub Pages, ветка `main`).
Обновление: закоммитить и запушить в `github.com/wizzhomie/portfolio` — Pages пересоберётся сам.

Одностраничный сайт-портфолио по макету: тёмная bento-сетка, стеклянная лента в hero,
восемь плиток экспертизы, четыре проекта, схема пайплайна, стек, принципы и финальный блок с CTA.

Сделан без сборки и без внешних зависимостей: чистые HTML + CSS + JS. Открывается любым
статическим сервером.

## Как посмотреть

```bash
cd ~/portfolio-site
python3 -m http.server 8790
```

Затем открыть `http://127.0.0.1:8790` (или `http://<адрес-сервера>:8790`).

Открывать файл напрямую через `file://` не стоит: браузер заблокирует загрузку шрифта Inter
из-за политики CORS, и типографика подменится системной.

## Структура

```
index.html        разметка всех секций
styles.css        токены, сетка, адаптив, анимации
main.js           появление блоков при скролле, мобильное меню, параллакс арта
assets/           шрифт, лента, логотипы, фото Земли, фавикон
tools/            генератор ленты и скриншотов (для разработки, на сайт не влияет)
shots/            контрольные скриншоты
```

## Что легко поменять

- **Тексты и ссылки** — в `index.html`. Заголовки, описания проектов, e-mail, GitHub.
- **Цвета и типографика** — переменные в начале `styles.css` (`:root`).
- **Проекты** — четыре блока `<a class="project">`; ссылки сейчас ведут на
  `github.com/wizzhomie`, их стоит заменить на реальные страницы кейсов.
- **Графика в hero** — `assets/hero-schematic.svg` (изометрические блоки на сетке);
  пересобирается скриптом `node tools/gen-schematic.js`.

## Адаптив и доступность

- Проверено на ширинах 360–1920 px, без горизонтального скролла.
- Мобильное меню: кнопка с `aria-expanded`, закрытие по Esc и клику мимо.
- Все анимации отключаются при `prefers-reduced-motion`.
- Контент остаётся видимым без JavaScript (через `<noscript>`).
- Иконки декоративные и скрыты от скринридеров, у логотипов есть `alt`.

## Источники графики

- Логотипы технологий — [Simple Icons](https://simpleicons.org) (CC0), локальные SVG.
- Земля — снимок NASA «The Earth seen from Apollo 17» (public domain, Wikimedia Commons).
- Изометрическая схема в hero и все миниатюры проектов — сгенерированы/свёрстаны
  для этого макета, сторонних изображений нет.
